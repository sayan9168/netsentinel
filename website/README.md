# AOXNet Website

A dependency-free static documentation site for AOXNet.

## Local preview

From the repository root:

```bash
python3 -m http.server 8080 --directory website
```

Then open `http://localhost:8080`.

## Deployment

The site is static and can be deployed to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static web host. No backend or AI API is required.
