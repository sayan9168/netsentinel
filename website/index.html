Security boundary

CRC32 is not authentication. For untrusted networks, use TLS 1.3; use mTLS when both peers require certificate-based identity. Application authorization remains a separate responsibility.

Production posture

Use the repository's production checklist before deployment. Validate formatting, vetting, unit tests, race tests, fuzzing, benchmarks, TLS policy, resource limits, load behaviour and application-specific security requirements.
